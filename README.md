# Urban One Business Modeling Website

This static website is designed for GitHub Pages. It preserves the Week 1 navigation headings and adds Week 2 sections.

## Files
- `index.html` — Introduction
- `proposed-business-model.html` — Proposed Business Model
- `business-process-analysis.html` — Business Process Analysis
- `pricing-analysis.html` — Pricing Analysis
- `references.html` — References
- `styles.css` — Shared styling
- Diagram PNGs — embedded in the Week 2 pages

## Publish with GitHub Pages
1. Upload these files to the root of `https://github.com/PythonPatchez/urban-one-business-model`.
2. In repository Settings → Pages, select Deploy from a branch, choose `main` and `/ (root)`, then Save.
3. Wait for the deployment workflow to finish.
4. Open the published URL and test every navigation link and image.
5. Replace the Power BI placeholder with the actual shared report URL.

The website does not claim that a Power BI report has been published.
